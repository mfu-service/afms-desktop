## AFMS Desktop 1.1.0

Windows app for the University of El Oued AFMS platform:
https://ft-edugate.univ-eloued.dz/

### Downloads

Anyone can download these files (public release):

- **AFMS-Setup-1.1.0.exe** — installer (Start Menu + desktop shortcut)
- **AFMS-Portable-1.1.0.exe** — run without installing

### What's new

- Multiple tabs to browse several pages at once
- New tab / close tab shortcuts (`Ctrl+T`, `Ctrl+W`)
- Switch tabs with `Ctrl+Tab` and `Ctrl+1…9`
- Open in-app links in a new tab from the context menu
- Tabs are restored when you reopen the app

### Notes

- Login and session stay inside the app (shared across tabs)
- University site pages stay in the window; other links open in the browser
- Windows may warn that the publisher is unknown; choose **More info** then **Run anyway** if you trust this university build
